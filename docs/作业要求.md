# 作业要求

> 课程：欧美流行音乐鉴赏
> 形式：学期论文（按学校下发的《学期论文》模版排版）

## 一、内容要求

1. **题目自定**，内容为介绍你最喜欢的欧美音乐歌手或组合。
2. 正文 **800 字以上**（不含封面、摘要、参考文献）。
3. 需要有摘要（中英文均可，按模版为英文 Abstract）、关键词与参考文献；
   参考文献只列真实可查的来源，不编造条目。

## 二、格式要求

按 `original/学期论文模板（终）.doc`（或 `original/官方导出示例.pdf`）排版，
用本仓库的 LaTeX 模版可以得到同样的效果：

| 项目 | 要求 |
| --- | --- |
| 纸张 | A4，正文双面打印 |
| 封面 | 学校模版封面：校徽、学 期 论 文、作者/学号/学院/专业/题目/指导者、年月、得分框 |
| 摘要页 | 单独一页，题目 + Abstract + Keywords，整页细框 |
| 正文 | 小四号宋体 + Times New Roman，1.5 倍行距，首行缩进 2 字符 |
| 标题 | 一级小三黑体、二级四号黑体、三级小四黑体 |
| 图表 | 图题在下、表题在上，五号黑体，按章编号；表格用三线表 |
| 参考文献 | 另起一页，标题小三号居中，条目小四号、18 磅行距 |
| 页码 | 页眉阿拉伯数字，奇数页在右、偶数页在左 |

## 三、提交

按课程要求提交 PDF（文件名自定，建议“姓名-学号-题目.pdf”），
同时保留 `.tex` 源文件以便修改。

## 四、说明

- 封面“得分”框由教师填写，学生留空；
- 模版顶部的蓝色/红色说明文字属于使用提示，正式论文中不出现；
- 校徽等素材版权归南京理工大学所有，仅限课程作业使用。
